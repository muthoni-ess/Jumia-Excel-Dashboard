# Jumia-Excel-Dashboard
An Interactive Excel Dashboard for Jumia Product Analysis
### Introduction
Jumia is one of Africa's leading e commerce platfrom that manages millions of transcations with diverse products.

### Objective
My aim is to build an interactive excel dashboard using Jumias transactional,disorganized data.

### Tools Used
- Excel
- Pivot tables
- Pivot charts
- Excel Functions
- Slicers
- Data Visualization tools

 ### Project Tasks
 - Data cleaning
 - Data analysis
 - Data Visualization
 - Dashboard design

### Final Submission
Excel dashboard file(.xlsx)with original dataset,cleaned dataset and dashboard.A README.md document explaining about the project.
